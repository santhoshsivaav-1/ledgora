# ITR-3 JSON schema

`AY2026-27.json` is the Income Tax Department's published JSON schema for ITR-3, assessment year 2026-27, file
`ITR-3_2026_Main_V1.1.json`, downloaded unchanged from
https://www.incometax.gov.in/iec/foportal/downloads/income-tax-returns (the same page also offers the Excel utility
`ITR3_AY_26-27_V1.4.zip`).

Each assessment year: download the new schema, add it here as `AY<year>.json`, register it in `src/itr3Schema.ts`, run the tests.
